# Mobile navigation fixes — 1 October 2026

## Findings and changes

- The sidebar scrim was a CSS pseudo-element with no click handler. Replaced it with a separate backdrop button that closes the drawer.
- Links to the current hash did not trigger routing, leaving the drawer open. Sidebar link activation now closes it directly.
- Mobile CSS used translucent sidebar gradients. Drawer and navigation entries now use opaque theme surfaces in both themes.
- The page behind the drawer could scroll. Opening locks body scroll and makes main content inert; closing restores the previous scroll position.
- Focus trapping missed buttons inside the track switcher's shadow root. The controller traverses shadow controls; Escape closes an expanded track dropdown first, then the drawer. Closing returns focus to the hamburger. Desktop resize clears modal state and scroll lock.
- Header controls had inconsistent mobile placement and navigation labels disappeared. Header now reserves columns for controls and shows labeled navigation without horizontal scrolling at 320 px. Header controls have at least 44 px touch areas; sidebar entries at least 48 px.
- Long topic source links overflowed narrow lesson screens. Links now wrap within content width.
- Mock controls used too much vertical space on phones. Compact two-row layout retains timer, pause, answered count, quit and submit. The redundant graphical progress bar is hidden on phones; answer count remains visible.
- Search results extended below short landscape screens. Mobile dialogs now fit within viewport height with internal scrolling.
- Added safe-area viewport support, drawer padding and overscroll containment. Reduced-motion preferences remain supported.

## Verification

Browser viewport tests: 320 × 568, 390 × 844, 768 × 1024, 844 × 390, 1024 × 768. Checked home, a PSA lesson, PSA/PBA mocks, Smart Review, search and settings. No document horizontal overflow in measured screens. See `mobile-layout-measurements.json`.

Verified backdrop/close/Escape, same-route navigation, track selection, five repeated open/close cycles, keyboard focus wrapping and mobile-to-desktop resize. Screenshots: `../screenshots/mobile-menu-light-fixed.jpg` and `../screenshots/mobile-menu-dark-fixed.jpg`.

`npm run check`: 31 passing tests, 74 JavaScript files. Three new controller regressions cover dismissal, scroll/focus restoration, same-route navigation, desktop resize and shadow focus wrapping. Initial shell remains within the existing 300,000 byte budget; redundant CSS comments/spacing were reduced without changing declarations.

These are desktop browser viewport tests. Physical iOS Safari, Android Chrome, VoiceOver and TalkBack sessions remain unverified. Release service worker version: v43. Commit/push/deployment status is recorded in Git and [GitHub Actions](https://github.com/emredursun/quilyn/actions); this document records verification scope.
