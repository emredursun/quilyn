Linking a TestSheet to a Template

A Template alone can't run as a test — it needs the TestSheet to supply the specific data for each generated TestCase (like knowing what color and transmission to put in our car-blueprint analogy).

Jump to Schema Definition — once linked, a new ribbon option appears under the TestCase tab. Right-click the Template → Jump to Schema Definition (shortcut: Ctrl+J) to instantly navigate to its linked TestSheet. You can also confirm the linked TestSheet's name via the Property tab.

Linking Values (the XL Reference)

Linking the TestSheet doesn't automatically tell Tosca which TestStepValue uses which piece of data — you must link the individual Values.

Check Template

Right-click the Template → Check Template to validate that all XL references actually resolve to something in the TestSheet. Important: this ONLY checks that the links exist — it does NOT check for functionality errors in TestSteps or formulas. The function highlights the TestStepValue containing the broken link, not the XL reference text itself.

Check Template validates reference EXISTENCE only. It will not catch a wrong formula, a bad Condition, or incorrect TestStep logic — those still need manual review or a test run to surface.

An XL reference can also be typed manually, using the syntax {XL[Attribute.SubAttribute]} or {XL[Attribute.SubAttribute.SubSubAttribute]} — but this is NOT best practice. Drag-and-drop is preferred since it avoids typos and guarantees the path actually matches the TestSheet's structure.

Instantiating the Template

Once the Template is complete and its Workstate is set to COMPLETE, the next step is Instantiation — the process where Tosca creates actual TestCases based on the TestSheet (and any Conditions, covered in a later lesson).

For our example, instantiation creates 4 TestCases — one per TestSheet Instance. Each generated TestCase shows only the steps/values relevant to it (e.g. the ValidValues TestCase uses the default size M; the Wrong-size TestCase uses the invalid XL) — Values from the TestSheet replace the References.
