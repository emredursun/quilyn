Centralized Data and Automated Flow

TestCase-Design organizes test data; a Template models a reusable flow. Linking a TestSheet to a Template and instantiating it produces concrete automated TestCases. This local track provides independent notes and practice, not the Academy videos or solution workspaces. A useful study routine is to read the concept, build a small example, verify its assertions, and compare it with current documentation. Original course lesson counts, durations, transcript and workbook contents have not been verified.

Check Your Working Environment

The TestCase-Design AddIn is installed and enabled by default with a complete Tosca installation and requires a valid license. If disabled in Project > Options > TestCase-Design, it starts read-only after restarting Commander. Reuse a suitable working installation, but check its current license, AddIn and target-browser requirements; AS1 completion alone does not guarantee that these still work. Follow vendor-supported platform requirements rather than assuming every Windows VM on macOS is supported.

Troubleshooting: Tosca Commander License Pop-ups

If your organization uses a cloud license server, first confirm your administrator added your account. In license configuration, select Setup > Change connection > Connect to Cloud hosted License Server and sign in using Support Hub credentials. Enable the default-proxy option when your environment requires it. A license prompt is not proof that the cloud connection alone is the cause; inspect the configured license source and available entitlement.
