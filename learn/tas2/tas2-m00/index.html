How This Course Is Organized

AS2 ("Optimizing Test Automation with Centralized Test Data") builds directly on AS1. Instead of building one TestCase at a time, you'll learn to centralize test data in TestSheets and turn a single TestCase into a Template that generates many TestCases at once.

Each of the 8 lessons follows the same pattern

Designed so you can move through the course quickly and predictably:

  • A video tutorial covering the key concepts
  • A See and Try section to practice the steps yourself
  • One or more exercises for hands-on practice
  • A solution video demonstrating the step-by-step process
  • A short quiz (most lessons) to check your understanding

Prerequisites (Same as AS1)

Nothing new to install

If you already completed AS1 in this same environment, you're ready — AS2 reuses the exact same setup.

  • Tricentis Tosca On-Premises installed (Windows, or Windows VM on macOS)
  • A valid Tosca license, active in Tosca Commander
  • Tricentis Automation Extension installed and enabled in Chrome

If you're starting fresh with AS2 and skipped AS1, see Section 0 of the AS1 track in this app for full installation steps (Tosca install, license request, Chrome extension, and the macOS Windows-VM workaround).

Troubleshooting: Tosca Commander License Pop-ups

Tosca keeps showing a license pop-up on launch?

This usually means Tosca Commander isn't connected to a valid license source. If your organization uses a Cloud License Server, connect Tosca directly to it: access the license configuration, go to the Setup tab, select Change connection, choose Connect to Cloud hosted License Server, then sign in with your Tricentis Support Hub credentials (enable Use default proxy if your organization requires a proxy).

Tricentis Academy Certifications and Badges

Same as AS1: finishing AS2 does not end with a formal certification exam. It ends with the final quiz described above, which earns you a Badge and points — not a Certificate. Tricentis reserves Certificates for its multi-course "Product Consultant" learning paths; AS2, like AS1, is one course inside the Tricentis Tosca Product Consultant path, not a path by itself. Badges appear on your Academy "Badges" page with a shareable verification link.
