Grand Scenario: Order Your Own Computer

Objective

Build your own data-driven test to automate ordering a customized computer from the DemoWebShop — practicing everything learned in the course in one more complex, project-like Template.

Business context: products (like computers) have configurable features, each affecting price. You'll select different computer features (each with a defined price), place the order, and verify Tosca calculates the correct total — using a Template built from the Product Configuration TestSheet.

FeatureOptions & Surcharge
Base packageCheap computer = $800.00 (standard) · Expensive computer = $1,800.00
ProcessorSlow = $0 · Medium = $15.00 (standard) · Fast = $100.00
RAM2 GB = $0 · 4 GB = $20.00 (standard) · 8 GB = $60.00
Hard Disk Drive320 GB = $0 (standard) · 400 GB = $100.00
SoftwareOffice Suite = standard · Image Viewer = +$5.00 · Office Suite (alt) = +$100.00 · Another Office Suite = +$40.00 (only ONE Office Suite allowed per order)
PaymentCOD (Cash on Delivery) only — remember its surcharge in the Total price calculation

If BOTH Office Suite options are selected in the same order, the TestCase should skip the checkout process entirely and log out immediately — this is an intentionally invalid combination.

All needed Modules live under: Web Shop >> Products >> Products Category Computers Module Folder — check there first instead of scanning the SUT yourself.
