Where API TestCases Come From

API Scan can create messages and export selected objects into Commander Modules and TestCases. Inspect the resulting request/response model, endpoint, authentication and assertions before execution. No developer-provided subset was available for this review; local country/product examples are hypothetical, not verified current Demo Web Shop functionality.

Communication Pattern Depends on the Transport

For the synchronous web-service example, model a request and verify the corresponding response. This is not a universal rule that every API interaction must consist of exactly two steps; queue push/pull and other transports have different message workflows. Check the transport and expected communication pattern.

Building the API Template (Same Flow as UI)

The common Template workflow still applies: prepare the flow, convert, link the data source, inspect XL paths, set generation conditions as required, check and instantiate. API-specific endpoint, authentication, payload, transport and assertion behavior still need separate review. Schema validation and generation do not prove the response meets the business contract.

Independent Product API Example

Independent product example: send a synthetic SKU through an authorized test endpoint and compare returned product fields with agreed expected data. Request payload values use Insert in the documented simple example; response fields being asserted use Verify. Structural selection, buffering or other purposes may require other ActionModes. CP recalls a scoped Test Configuration Parameter, potentially inherited or overridden, rather than a guaranteed project-wide value. Do not assume product ID 36 or catalogue visibility from an inaccessible original exercise.

Mapping and Generation

Convert the prepared API flow to a Template and map synthetic inputs and expected outputs. Deliberately replace an old Value only if that mapping is intended; composed expressions can be legitimate. Inspect unwanted leftover text alongside an XL path without deleting intentional prefixes. Generate, review and trial-run the concrete cases against the agreed contract.

Original Material Access

Original Academy exercise instructions, API subset, endpoint contract and solution material were inaccessible and remain unverified. Use the independent example with authorized non-production access; no original API exercise was executed during this review.
