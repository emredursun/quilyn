The four combinatorial methods

All Combinations

Generates the product of defined value choices. Independent unconstrained example: three Attributes with three choices yield 27 datasets. Generated combinations are design Instances, not already executed TestCases.

Orthogonal

Uses every defined value at least once while keeping the combination set small. Independent unconstrained example: three Attributes with four choices can cover all values in four rows; this is value coverage, not all pair coverage.

Pairwise

Covers every value pair between two Attributes. This is stronger interaction coverage than merely using every value once, but does not establish full higher-order coverage.

Linear expansion

Starts with a defined StraightThrough baseline and varies one non-baseline value per row. In a simple model with one baseline choice per Attribute and nine alternate values in total, this gives ten datasets. The relation-aware variant can add, exclude or constrain combinations.

Choosing a method

It depends on the project

The current documentation offers methods for different project needs; it does not establish a universal default or an industry-wide legal mandate. Select a method based on specified coverage, business dependencies and applicable project constraints.

Building combinations manually in Tosca

Instances as combination columns

Right-click a TestSheet, TestCase-Design Class or Attribute and select Generate Instances, then the desired method. These design combinations can later support TestCase organization and template instantiation.

Combining at Attribute level vs TestSheet level

You can generate on a selected Attribute or a TestSheet, and can select particular Attributes or Instances. Confirm the generated values in the selected scope rather than assuming a particular highlight color proves coverage.

You must be focused on a particular level (TestSheet or a specific Attribute) to see that level's Instance columns.

Keeping a TestSheet manageable

Arrange Instances

Optimize Instances → Arrange Instances arranges the selected Attribute’s Instances; the dynamic-menu reference documents Ctrl+R. The accessed reference does not specify the earlier lesson’s exact five-category sort order.

Merge Instance Duplicates

Merge Instance Duplicates merges duplicates with matching values, Character and Position. Matching display names or values alone do not establish every property is identical.

Inspect Instance Usage to see how often a value participates in combinations; adding that column changes the view, not the dataset.

The keyboard reference lists F9 for Show or hide, including Instances. F12 separately shows/hides TestCase-Design instance symbols. Shortcuts apply to the active window.
