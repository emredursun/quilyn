What a Class is

Class

A reusable Tosca object — conceptually similar to a Library in the TestCase section — that lets you define an Attribute structure (with its Instances and combinations) once and reuse it across many TestSheets via a Class Reference. A typical candidate is data that shows up repeatedly, like a Customer Attribute structure used by every TestSheet that touches customer data.

Why it matters

Reuse saves setup time, and because a Class Reference stays linked to its source Class, updating the Class once propagates that change to every TestSheet referencing it — centralizing maintenance instead of repeating it in every TestSheet.

Four ways to create a Class

Dragging an Attribute WITHOUT top-level combinations

If the Attribute structure you drag doesn't already have Instances/combinations at its top level, Tosca asks you to choose: 'Create Class from Attribute' copies the structure AND auto-generates Instance combinations based on the combinations that already existed in the source TestSheet. 'Create Structure from Attribute' copies only the Attribute/Instance structure, with no combinations.

A Class Reference is visually distinguished by a white arrow overlay on its icon.

Working with Class References

Editing a Class

Once created, a Class can be modified exactly like a TestSheet — add or remove Attributes, create or delete Instances, adjust combinations, and set Character/Position on its Instances.

Resolve Class Reference

As with Libraries, if you want to change or remove a Class without affecting the values currently shown in a particular reference, select 'Resolve Class Reference' on that reference first. This breaks the live link, letting that instance of the data be modified or the Class removed independently.

Unused Instances vs irrelevant Attributes

Not every Instance in a Class needs to be used in every TestSheet that references it — Instances not selected in a given Class Reference's combinations are shown bolded in the TestSheet. Separately, whole Attributes inside a Class Reference can be marked irrelevant for a specific TestSheet using the 'Relevant' column (add it via the Column Chooser): unchecking the box for an Attribute grays it out. Press F11 to toggle hiding/revealing these irrelevant Attributes.
