Design for reuse

Spot reuse early

When creating multiple TestSheets, watch for Attribute structures that will show up again elsewhere, and convert them into Classes (Lesson 6) rather than rebuilding them each time. A Class can then be amended — immediately or as the project evolves — to include new data variations, and every TestSheet referencing it benefits.

The recommended core structure

Keep using the four-Attribute skeleton from Lesson 2 as the backbone of every TestSheet: Administration (BusinessRelevant = No), Precondition and Process (BusinessRelevant = Yes), and Verification (BusinessRelevant = Result). Populate each with the relevant sub-Attributes and Instances for that Requirement.

Structuring for Agile: Given-When-Then

Given-When-Then

A template for writing acceptance tests for user stories, useful when TestCase Design needs to reflect an Agile way of working. An acceptance test built this way has three parts: Given (the context and preconditions), When (the action being carried out), Then (the observable, expected outcome).

Worked example

User story: 'As a returning customer, I want my saved shipping address pre-filled at checkout, so I can complete an order faster.' Written as Given-When-Then: Given a registered customer with a saved shipping address is logged in, When they proceed to checkout, Then the saved address should be pre-filled and the customer should be able to confirm the order without re-entering it.

This maps naturally onto the core Attribute structure: Given → Precondition, When → Process, Then → Verification.

Building structure outside Tosca first

Why plan externally

For a large or complex TestSheet, it can be faster to sketch the Attribute hierarchy in Notepad or Excel first, then import it in one shot, instead of creating each Attribute by hand inside Tosca.

After building the structure, select and copy it all, then right-click the target TestSheet and choose 'Create Element Structure from Clipboard' (also available in the Ribbon). Tosca creates the matching Attribute hierarchy automatically.
