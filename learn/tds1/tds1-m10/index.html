Automating what you've done manually

The goal

TestCase Design exists to generate complete test data sets from the Attributes and Instances you've defined. Everything built manually so far — combining at a lower Attribute level or at the TestSheet level using Linear Expansion — can instead be generated automatically by Tosca in one action.

How it works

Focus on the level where you want combinations created, and Tosca instantly combines every structural element beneath that level according to the combinatorial method you select.

Generating at a lower Attribute level

Prerequisite: an empty Instance Folder

To generate Instances automatically on a specific Attribute, that Attribute first needs an empty Instance Folder — because the lower Attributes being combined will automatically combine into the next Instance Folder above them. Create this by adding an Instance (which creates both the Instance itself and its containing Instance Folder), then deleting just the Instance while keeping the Folder.

Generating

With the Instance Folder in place, select the Attributes to combine, right-click, choose 'Generate Instances', and pick the combinatorial method. The combinations appear as Instance columns according to that method.

If using Linear Expansion, the StraightThrough Instances MUST be marked before generating. Linear Expansion needs a baseline (the all-StraightThrough combination) to expand outward from — without it, the method has nothing to switch values against.

Generating at the TestSheet level

Simpler — no Folder setup needed

At the TestSheet level, there's no need to pre-create an Instance Folder. Just right-click the TestSheet itself, select Generate Instances, and choose the method. Any combinations already created at lower levels are automatically taken into account when Tosca generates at the TestSheet level.

Attributes set to BusinessRelevant = No or Result are excluded from automatic generation — only BusinessRelevant = Yes Attributes participate in combinatorics.

Generate Instances vs Complete Instances

The problem with re-generating after a change

If a new Attribute is added later and 'Generate Instances' is run again, Tosca does not account for the combinations that already existed — it can recombine everything and potentially create duplicates.

Complete Instances

The fix: 'Complete Instances' only creates the new combinations required to cover the newly added Attribute, leaving existing combinations untouched and un-duplicated. It works the same way as Generate Instances — available at both the TestSheet and Attribute level, via right-click → Complete Instances → choose method.
