What is an Instance

Instance

An Instance specifies a variation of an Attribute. Create it with Create Instance or Ctrl+N, Ctrl+I; use a unique name. Tosca can also create Instances from entered Attribute values or an XModuleAttribute.

Instances live in Instances Collections. Creating the first Instance under an Attribute creates the collection automatically.

Character: Valid, Invalid, StraightThrough

Valid (default)

Valid is the default Character: the value fits the business process and no validation error is expected.

Invalid

Invalid means the input should be rejected. Independent example: a wrong password test passes only if the implemented checks confirm the required rejection, message and absence of a session; the Character label does not itself execute assertions.

StraightThrough

StraightThrough identifies a frequently used path with few dependencies and high business risk if it fails. Linear expansion needs this baseline. It is not merely any default Valid value.

Use Toggle Character in the TestCase Design dynamic menu or edit Character in Properties. StraightThrough automatically sets Position to Inner, which cannot be changed while that Character is selected.

Position: Inner vs Boundary

Boundary Value

Boundary values are at or around an accepted range edge. Independent integer-age example: 0/1 and 99/100 exercise rejection and acceptance around an inclusive 1–99 range; verify the business rule rather than assuming every range has identical boundaries.

Regression risk at boundaries

Do not assume a boundary defect is permanently impossible after one test. Changes in validation, data conversion or surrounding logic can reintroduce it even when the published range is unchanged. Keep relevant boundary checks in regression according to risk.

Inner Value (default)

Inner values are away from a chosen boundary. Independent grouping example: if all ages 2–98 follow the same business behavior, choose a representative from that group. If additional age thresholds change behavior, split the group instead of treating all inner values as equivalent.

Change Position with Toggle Position or Properties. Valid and Invalid Instances can be boundary values; StraightThrough is restricted to Inner.

Group values only when their expected behavior justifies it. Random choice alone does not establish equivalence or replace boundary checks.
