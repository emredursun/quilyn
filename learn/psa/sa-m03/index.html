Users and Personas

User

An individual who interacts with the application to perform work. Each user is represented by an Operator ID record that stores their profile and credentials and links them (via an Access Group) to an application, portal, and roles.

Persona

A CATEGORY of users who interact with a Case in the same way and share the same access needs — for example Customer, CSR, or Manager. Many individual users can be assigned to a single Persona for role-based access.

Users-to-Persona relationship

You assign each user to a Persona based on HOW they interact with a Case. The Persona determines which application/portal and access the user receives; adding a Persona to a user grants that user the Persona's access.

A Persona is a job title (e.g., 'Dispatcher') with a defined set of door keys; a user is the individual badge. Assigning a user to a Persona programs their badge with that title's keys (access).

Managing Personas and Channel interfaces

Channel interface

The way a Persona interacts with a Case — for example a Web portal, mobile, or digital messaging. Personas and Channels together (the second application pillar) describe who participates and how they reach the work.

Managing Personas/Channels in App Studio

As a System Architect you add and manage an application's Personas and their Channel interfaces in App Studio, tailoring each Persona's experience to the work they do.

If the Persona is the role on the cast list, the Channel is the stage door they enter through (web, mobile, messaging). The same Case can be reached through different doors per Persona.

Inviting a user and adding a Persona

Inviting a user

You invite a user to an application so they can log in and perform work. Inviting creates/associates the user's Operator record with the application's access configuration.

Adding a Persona to a user

You add a Persona to an application user to grant the access and responsibilities tied to that Persona. Because Personas map to Access Groups/Roles, this is how you control what work and functionality the user can access.

Inviting a user is issuing them a badge; adding a Persona is programming which areas that badge unlocks.
