Controls and Presentation

6 default control types

Pega automatically pairs each field with an appropriate control type based on the field's data type. The 6 defaults are: Autocomplete controls, Check boxes, Drop-down lists, Links, Rich-text editors, Text input. Note: Radio buttons are NOT in this list.

Themes

Themes configure the STYLING of UI elements — buttons, links, headers. The out-of-the-box theme is Pegasus. Configure themes in App Studio at Settings → Themes. Themes control appearance only, not behavior.

Dynamic UI — Purpose and Benefits

Dynamic UI is like a smart insurance application form. If you answer 'No' to 'Do you own a vehicle?', the entire vehicle section disappears. If you select 'Text' as your preferred contact, the mobile number field becomes required. The form adapts in real time — no page reload needed.

Dynamic UI — purpose

Designing UI elements to adapt according to user choices. Provides:

  • Real-time response to end-user behavior
  • Robust functionality for most interactions
  • Reduced visual clutter
  • Fewer full-page refreshes for improved responsiveness

Dynamic Attributes — Visible, Disabled, Required

Visible attribute

Controls whether a UI element is shown:

  • Default: Always (always visible)
  • Options: Always | Never | Custom Condition | When Rule

Disabled attribute

Controls whether a UI element is read-only:

  • Default: Never (always editable)
  • Options: Never | Always (always read-only) | Custom Condition | When Rule

Required attribute

Controls whether a field must be filled before the form submits:

  • Default: Never (optional)
  • Options: Never | Always | Custom Condition (required when expression is true) | When Rule
  • Note: 'If not blank' and 'If not zero' are NOT available for Required — only for Visible/Disabled

Custom Condition vs When Rule

Two ways to configure conditional display in Dynamic UI:

  • CUSTOM CONDITION — for SHORT, one-off expressions (e.g., check one dropdown value)
  • WHEN RULE — for COMPLEX or REUSABLE conditions shared across multiple UI elements

'If not blank' and 'If not zero' — Visible ONLY

'If not blank' shows an element only when the field value is not blank. 'If not zero' shows when the value is not zero. These options appear ONLY under the Visible attribute — not under Disabled or Required.
