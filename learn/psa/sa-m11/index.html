Case Status

Case status

A value that communicates where a Case stands in its life cycle (e.g., New, Pending-Approval, Resolved-Completed). Status guides users on what is happening, drives reporting, and can trigger notifications. The work status is stored in the standard property pyStatusWork.

Case status and assignment instructions are like a traffic light and GPS directions combined: the status indicator tells everyone where the case is in its journey (Open / Pending-Approval / Resolved), while the step instructions are turn-by-turn directions telling the current worker exactly what to do before pressing 'Submit.' Miss either one and the driver is left guessing at a green light.

Status categories

Four conventional Case status prefix categories:

  • New — just created
  • Open — in progress
  • Pending — waiting on something or someone
  • Resolved — closed (e.g., Resolved-Completed, Resolved-Rejected); a Resolved- prefix closes the Case

Setting status

You set a Case status as part of the life cycle — for example automatically when a Stage or Step is reached, or with a Change/Set Status automation. Choosing meaningful statuses keeps users and reports aligned on progress.

Guiding users: instructions, help text, and visual cues

Step (Assignment) instructions

Text added to a Collect-information Step/Assignment that tells the user exactly what they must do to complete the Task. Instructions render at runtime on the assignment form, reducing confusion and errors.

Field-level help text

A short, PERSISTENT description shown beneath or beside a field label to guide the user on what to enter (valid values, format, examples). Always visible — it does not require hovering.

Tooltip

A short hint shown ON HOVER over an information icon or label. On-demand and space-saving — use it for an occasional one-sentence tip, versus persistent help text for guidance the user always needs.

Visual cues are presentational, not logic

Optional/required indicators, decorative badges, inline status messages, and conditional alert banners are DISPLAY-ONLY guidance — shown/hidden with visibility conditions, but business logic belongs in automations, decision rules, and data transforms.

Progress and navigation indicators

For a long, multi-section form or process, a navigation panel / progress indicator shows the user where they are (current step highlighted, sections completed). This orients the user across the Task, complementing per-field help text.
