Explore Data Landing Page

Insights are like saved spreadsheet pivot configurations: you build the query once (pick fields, filters, chart type), save it with a name, and anyone with the right access can open that same 'view' of the data. The Explore Data landing page is the workbench where you build and store these configurations.

Explore Data landing page

A View-based landing page where you can explore and analyze application data. Query data, then sort, filter, and group results. It is the preferred data exploration tool for Constellation design system applications.

Insights — definition

Rules that Pega Platform uses to transform data queries into tables or visualizations (lists or interactive charts). Insights can be saved and shared between users. Created via the Explore Data landing page.

Table-based Insights

Display a custom data query as a table on the Explore Data landing page. You can create a new table-based Insight or select a previously-created one to view or modify.

Chart-based Insights

Visualize a custom data query as a chart (e.g., bar, line). You can create a new chart-based Insight or select a previously-created one to view or modify.

Simple value chart — Measures only

A chart sub-type providing a high-level summary of data. To configure: in the Fields section, select fields in the Measures area ONLY. The Display as list then updates to include simple value options.

Traditional UI + Explore Data

For apps built with Traditional UI architecture, you must enable the option to 'use Constellation UI to render landing pages' before you can use Explore Data.

Applying Insights Across Components

Insights in full Page Case Views

Add a custom Insight to a tab in a full Page Case View to improve visibility into Case-related data. Example: configure the Details tab of an Order Case Type to show a chart visualizing product orders over the last quarter.

Insights in Portal landing pages

In Portal configuration, available landing pages are shown in the configuration pane. In addition to fields, Views, and Widgets, you can add an existing Insight to a region of a selected landing page.

Dashboards — definition

Dashboards organize related Insights into a customized interface with visual data tailored to user needs. Users can use templates to organize multiple Insights into layouts. Default dashboard: Work metrics dashboard.

Dashboard visibility settings

Three visibility levels for dashboards:

  • Private: visible only to you
  • Shared with Access Group: visible to members of that Access Group
  • Public: accessible to all users in the application

Promoted filter

A filter added to a dashboard that applies across ALL Insights in that dashboard. Helps users refine data views across multiple Insights simultaneously. Example: adding 'Item Category' filter to a dashboard with 3 sales Insights.

Troubleshooting Insights

Repeated login prompts

Troubleshooting: login loop issue:

  • CAUSE: inappropriate access token lifetime
  • FIX: update the token lifetime to match session requirements

Number separators confuse users

Troubleshooting: number formatting issue:

  • CAUSE: default UI controls display numbers with separators (e.g., 1,000)
  • FIX: modify UI controls to remove separators

Wrong object name in Explore Data list

Troubleshooting: incorrect data object name displayed:

  • CAUSE: Pega sources object names from the class short description
  • FIX: update the class short description to the correct name

Missing columns in Explore Data View

Troubleshooting: columns not visible in Explore Data:

  • CAUSE: insufficient user permissions for those columns
  • FIX: check and update user permissions to include access to the missing columns
