Cascading approvals: what and when

Ordered series

A cascade represents several required decisions in order. It is not an any-one broadcast or majority vote.

Think of a checklist of required reviewers: a small request may need a short management list; a regulated contract may also need a reviewer from another department. Decide who belongs on the list before designing the workflow.

Two models

Reporting structure uses management relationships; authority matrix uses a populated approver list.

Design questions

Which people are required? In what order? Does the number of management levels vary? Does anyone sit outside the reporting line?

Rejected outcome

Configure rejection flow explicitly. Resolution and revision are different policies; neither majority override nor restart should be assumed.

Reporting structure (and conditional levels)

Reporting source

At runtime the current-user context and selected Reporting Manager or Workgroup Manager source identify the reviewer. Do not assume the original creator is always the current user.

Depth

One requests the immediate manager; All uses the whole hierarchy; Custom uses When Rules to select the required depth. Depth is not a promise of arbitrary middle-tier skipping.

Challenge configuration

The linked v7 reporting-structure challenge uses Dev Studio, an Approve/Reject Step, Cascading and Reporting structure. Its When conditions select one or two levels; the walkthrough targets Platform 24.2.

Authority matrix

Approver data

An authority matrix needs a data structure of approvers. A Decision table, Data Page, Activity or Data Transform can populate it; a table is one supported approach.

Decision table example

The linked v7 challenge configures a Page List and an approver property, then a Decision table that appends required recipients. Evaluate all rows allows multiple matching results.

Other departments

Use the matrix when required reviewers are outside the chosen management line. List ordering still matters; population rules are not a parallel voting mechanism.
