Fields and Field Types

Field

A reusable UI component consisting of a NAME and a FIELD TYPE. Each field captures or presents one value associated with a Case. In Dev Studio a field is implemented as a property.

Fields and Views in Pega are like a spreadsheet: Fields are the individual cells that store raw data, Calculated values are the formula cells (=SUM(A1:A10)), and Views are the pivot tables — organized presentations of the same underlying data. You enter data once in a cell; multiple Views can present it differently without duplicating it.

Field Type

Determines the format/validation of the data and the input control rendered to the user. Choosing the right type (instead of Text for everything) enforces a consistent, valid format across all Case Types and reduces errors.

Single value vs. data relationship fields

Two categories of Pega Field Types:

  • SINGLE VALUE (basic) — captures ONE piece of data (e.g., text, integer, date)
  • DATA RELATIONSHIP (Embedded Data, Data reference, Case reference, Query) — connects a field to another data object or Case

Calculated Values

Calculated value field

A field whose value is COMPUTED automatically from an expression/formula that references other fields, rather than entered by a user (e.g., Line total = Quantity × Price per unit). It keeps derived data accurate and consistent.

Recalculation

A calculated value can be configured to recalculate as the underlying data changes, so it always reflects current inputs. Calculated fields are typically presented read-only because the system maintains them.

Views

View

A UI component that gathers data from a user OR displays data to a user, showing the fields and instructions needed for the current Step/Assignment. You add fields to Views to tailor the UI for each Step of the workflow.

View types & editability

Full Page View (read-only; one per Case/data object), Partial (read-only), List (relies on a data source; enable editing for create/edit/delete), and Form (editable; created per Step via Configure View). Default Form Views = Create and Edit.
