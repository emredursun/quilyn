Pulse

Pulse

Pega's built-in messaging system. Users post, view, and reply in the Pulse Activity Feed — directed to specific users, team members, or Case stakeholders. Example: a CSR posts once to update every Case participant on a claim's status.

Pega's Pulse collaboration is like a digital sticky-note wall inside each case: any team member can post a message, @mention a colleague, or attach a file — all permanently linked to that specific case. The conversation stays with the work, not scattered across disconnected email threads that someone has to manually reassemble later.

Accessing Pulse (developers vs. users)

Pulse collaboration access differs by role:

  • DEVELOPERS — click 'Toggle developer collaboration' in the App Studio header
  • USERS — access Pulse via a Pulse widget on their Case or Work Object

Replies and email notifications

Reply to a Pulse message with or without a comment. Users opt into email notifications for @-mentions, likes, replies in conversations they participated in, or posts to Cases they follow. Email replies appear as Pulse comments without login.

Tags

Tags

Descriptive words or phrases ASSOCIATED WITH A PULSE MESSAGE that categorize messages so users can quickly find information to resolve a Case. Add a tag by typing # followed by a word/phrase WITHOUT SPACES.

The Tags widget

Lists tags relevant to a Case. Each tag is a link — clicking it shows all Cases sharing that tag. Added to the Full Case Page (not the Navigation bar, where the Pulse widget lives).
