GenAI Design-Time Tools

Pega GenAI

A suite of generative AI-powered features integrated across Pega Platform, available beginning with Pega Infinity '23. It helps developers, learners, and users build applications, enhance learning, improve operational efficiency, and stay aligned with best practices.

Autopilot is a drafting assistant: use the proposal as a starting point, then check it against requirements. It does not know every implementation or replace professional validation.

Pega Blueprint

A separate SaaS design tool for collaborative application proposals. Review its suggested Case Types, data and Personas, then import the Blueprint into Pega Platform to accelerate development. The proposal is not automatically a production-ready application or a delivery-time guarantee.

Pega GenAI Autopilot

Design-time AI features in App Studio assist with workflow, fields, Personas and testing data. Review recommendations in context; claims about development-speed improvements are not a measured guarantee for an individual project.

Pega GenAI Connect

Lets you develop custom Pega GenAI-powered capabilities using the Pega GenAI gateway; an add-on compatible with Pega Platform, Customer Service, or Sales Automation.

GenAI Run-Time Tools and Custom AI

Pega GenAI Coach

Provides expert advice and feedback on END-USER tasks at application RUNTIME — ideal for task-specific guidance relevant to a Pega Case.

Pega GenAI Agent and Tool Rules

Automate Case processing and provide conversational support for run-time users. Agents perform automated actions and offer run-time guidance to accelerate Case processing; Tool Rules add governance, security, and compliance.

Pega GenAI Knowledge Buddy

Conversational answers grounded in an organization’s procedural documents and knowledge bases, useful while learning, developing or working. It can provide client-specific context; it is not restricted to generic employee questions.

Search Assistant & OpenAI search

Search Assistant integrates with Pega Community search (powered by Knowledge Buddy) to link relevant materials. OpenAI search on the Pega Documentation site answers questions when you add a question mark to the end of a search query.

Pega GenAI Autopilot at Design Time

What Autopilot accelerates

Autopilot delivers real-time, context-aware guidance and task prioritization during development. For a loan app, it suggests application components including Case Types, fields in the Data Model, and Personas — and developers can review and modify any recommendation before generating it.

The Autopilot workflow

When creating a Case Type, Autopilot can suggest:

  • Case Type name
  • Workflow (Stages/Processes/Steps)
  • Data Model fields
  • Personas
  • Sample data records
  • Form fill with sample data at runtime
  • Natural-language-generated Insights

Human-in-the-loop responsibility

Pega is NOT responsible for the content of Autopilot suggestions — always review AI-powered recommendations before accepting them.

Pega Blueprint (within the GenAI suite)

Blueprint as a SaaS design tool

Blueprint rapidly and collaboratively designs new applications and Case Types and operates INDEPENDENTLY as a SaaS tool — no Pega instance required to collaborate. The result imports into Pega Platform to jumpstart development.

What Blueprint proposes

From a business-terms description, Blueprint proposes Case Types, Case Life Cycles, Data Models, data objects, and Personas, plus best-practice application templates, enabling quick design edits to fit requirements.

GenAI Connect Step

Connect Generative AI automation Step

Since Pega Infinity '24, configure a Connect Generative AI Step in App Studio. A Connect Rule begins with a Prompt — the request for information sent to the Pega GenAI engine, custom to the Step or reused from Dev Studio.

Three response structures

GenAI response types and their Data Model mapping:

  • Structured - Single: one page/paragraph or field+value, auto-mapped to a Data Model field
  • Structured - List: bulleted fields/values mapped to an embedded data list
  • Unstructured: long/complex output — best practice is to map to a Text (paragraph) field

Target field requirement

You must identify a target field to write the response into, and add that target field to the application UI so the response can be displayed to the user.

Pega GenAI Agent and Tool Rules

Agents

Configurable AI assistants that automate Case processing and offer run-time guidance. An agent can run an automation, start a Case, call another agent, or launch a user action. Extend reach via agent-to-agent or MCP protocols.

Guardrails via Tool Rules

Detailed descriptions and guardrails ensure the agent responds precisely; at run time users converse with agents in natural-language chat. Agents can also process and extract data from uploaded documents, saving manual analysis time.

Generating a Case Type and Data Model

Case Type proposal

In App Studio’s Case Type tab, choose a suggested name or enter your own. Suggestions use the application name and metadata. Select the Autopilot option to propose a Life Cycle and Data Model.

Review before creation

Check and modify Stages and Steps against stakeholder requirements. Next proposes fields with Name, Type and technical ID. Edit names/types, add fields or remove unsuitable suggestions. Embedded Data and Data reference proposals can create associated data objects.

Create and inspect

Submit after review. Inspect the created Life Cycle on Workflow and the fields on Data model. A generated proposal is not proof that workflow, integration or security requirements are satisfied.

Generating testing data

Sample data records

Select a data object and open Records. Generate sample records with Autopilot and specify the desired number. The generated values correspond to field types; they can support tests before external data integration is available.

Fill a running test form

While testing a Case, Fill form with AI populates its form fields. These values become part of the Case data used during processing; they are test samples rather than verified production records.

Generating and using Personas

Persona proposals

Open Users > User management in App Studio. Autopilot proposes Persona names and descriptions from application metadata. Choose a proposal or enter a custom name, then review it against real stakeholder responsibilities.

Associate the Persona

After creation, add the Persona through the Case Life Cycle’s Personas & Channels area. Generating the business user model is not a guarantee of complete authorization or routing configuration.
