Duplicate Search

Search duplicate cases

Automation Step that identifies potential duplicate Cases by comparing field values. A duplicate occurs when a submitted Case matches an existing one. Example: same insurance authorization received twice — once online, once by fax.

Duplicate case detection in Pega is like a hotel reservation system that warns 'a booking already exists for this guest on these dates.' When a new case is submitted, Pega searches existing cases for matching criteria — if a match is found, the operator decides to proceed (create a new reservation) or merge (link to the existing booking). The search runs automatically; the human makes the final call.

Basic conditions — mandatory match

Conditions that MUST match exactly for a Case to be flagged as a duplicate. If ANY basic condition fails to match, the Case is NOT flagged — regardless of how many other fields match.

Weighted conditions — scored match

Each weighted condition carries a numeric score. When basic conditions match, the system evaluates weighted conditions and totals the score. Cases with sufficiently high scores are presented as potential duplicates for user review.

Resolving a duplicate

When the user determines the current Case IS a duplicate, they resolve it with the status 'Resolved-Duplicate'. This closes the duplicate Case and keeps the original.
