What Automations are

Automation

Automations simplify Case processing by providing configurable tasks, often performed by the system. Examples include email delivery, Case creation and data copying. The App Studio palette also lists Questionnaire, which asks a user for input; inspect each shape’s behavior rather than assuming every listed shape is purely system-side.

Think of workflow helpers: some deliver a message or copy data automatically, while others pause for a dependency or ask someone a question. Choose the helper whose behavior matches the requirement; its presence in the palette does not mean every downstream task avoids human work.

How to add an Automation

Two paths to add an Automation shape:

  • Case Life Cycle view: select a Step → More → Automations
  • Process modeler: Add → Automations (then configure with parameters specific to its purpose)

Automation vs. user Step

Distinguish automatic actions from tasks that require people or pause processing:

  • Collect information requires a person to supply data.
  • Run Data Transform executes configured logic without asking a person to re-enter it.
  • Questionnaire asks a user to complete questions; Wait pauses until its configured condition is fulfilled.

Automation shapes available in App Studio

Stage navigation shapes

Change to a Stage = move to a SPECIFIC Stage. Change to next Stage = advance automatically. Change to previous Stage = return to the previously visited Stage. Three distinct shapes — each behaves differently.

Case action shapes

CREATE CASE creates one or more Cases from the current Case, not necessarily only children. UPDATE A CASE targets the current Case or child Cases and descendants. PERSIST CASE makes a temporary Case permanent. SEARCH DUPLICATE CASES checks configured duplicate conditions.

Document & content shapes

ATTACH CONTENT associates a file, URL or note with a Case. CREATE PDF produces an attachment from a specified View; the reviewed topic notes that Constellation requires a workaround. GENERATE DOCUMENT handles Case documents and is a separate shape.

Communication shapes

SEND EMAIL — formatted emails to custom recipients. SEND NOTIFICATION — notification over multiple Channels. PUSH NOTIFICATION — iOS/Android mobile alert for a pending Case action. POST TO PULSE — posts a message to the Pulse feed.

Data, AI and waiting tasks

Key Automation shapes available in the Process modeler:

  • Run Data Transform executes a selected Rule.
  • Connect Generative AI uses configured prompts and response structures; enable and configure AI in application settings.
  • Wait pauses processing for a configured condition.
  • Questionnaire collects answers from a user. Decision branching is a separate workflow concept, not an additional item in this topic’s Automation table.

Use cases and selection

Send email — use case

Send automated email correspondence to all relevant parties with no user interaction. Example: an online store emails a customer about new offers. You configure how the application determines the recipient and compose the email content.

Run Data Transform — use case

Run a selected Data Transform rule at runtime to set/copy/initialize Case data. Example: at checkout, if the billing address equals the shipping address, a Data Transform copies it automatically instead of making the customer re-enter it.
