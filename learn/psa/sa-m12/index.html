Routing fundamentals

Routing

Routing assigns responsibility for completing a Task to one or more users. It increases business efficiency by ensuring the most appropriate users receive the right work at the right time, orchestrating the workflow across teams.

Work routing in Pega is like a hospital triage system: instead of patients (assignments) queuing randomly, a triage nurse (routing rule) directs each patient to the right specialist (worklist) or general waiting area (workbasket) based on urgency, skill, and capacity. Skills-based routing ensures the cardiac patient never waits behind a sprained ankle — and no specialist sits idle while their patients pile up elsewhere.

Worklist vs. Work Queue

Two types of Assignment containers:

  • WORKLIST — holds Assignments routed to a SPECIFIC user (operator) who owns the work
  • WORK QUEUE (work basket) — a SHARED queue for a team/Work Group; any qualified member can pull and complete the work

Routing options

Route to the current user

Keep the Assignment with the user already working the Case — appropriate when the same person should continue.

Route to a specific user

Send the Assignment to a named operator's Worklist when one accountable individual must own the Task.

Route to a Work Queue

Send the Assignment to a shared Work Queue when any qualified member of a team can perform the work.

Route using business logic

Determine the best-available user dynamically — for example by skill, availability, or other business rules — so work reaches the optimal person automatically.
