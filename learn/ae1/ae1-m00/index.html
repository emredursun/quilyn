What this course is about

Beyond the browser

AS1 and AS2 taught automation of web applications through the XBrowser Engine. But real end-to-end business processes rarely stay inside a browser: an order confirmation arrives as an email, a report is generated as a PDF, reference data lives in an Excel workbook, a back-office step runs in a Windows desktop application, and an approval may happen on a phone. AE1 covers the engines Tosca uses to reach all of those.

One tool, many engines

Rather than bolting on a separate tool per technology, Tosca exposes each technology through a dedicated Engine that plugs into the shared TBox framework. The way you build a TestCase — Modules, TestSteps, TestStepValues, ActionModes — stays identical whether you are steering a web page, a spreadsheet cell, or a mobile button. That consistency is the point of the framework, and it's what the next module covers.

This is a Deep Dive course and part of the Tricentis Tosca On-Prem Product Consultant learning plan. It assumes you already completed the Automation Specialist fundamentals (AS1/AS2) and are comfortable with Modules, TestCases, and ExecutionLists.

Before you begin

The course was developed on Tosca 16.0. Some screens in the lesson videos will not match a newer Tosca version exactly — the topics and features remain applicable, but expect cosmetic differences in dialogs and ribbon layout, as with any versioned training material.

Exercise prerequisite: create the AE1 workspace

Why a subset is used as a template

Each project gets its own Workspace. Subsets are how Tosca artifacts — including the Tricentis Standard Modules — are imported and exported. The course ships a base subset so every learner starts from the same Module set instead of building it up by hand.

Notice that the engine lesson folders (Excel Engine, PDF Engine, UIA Engine…) arrive empty. That is deliberate — you populate them by scanning during each lesson. The Standard Modules, by contrast, are supplied ready to use.

How the course is structured

Lesson → exercise → solution

Each lesson pairs a video with one or more hands-on exercises, and most exercises have a solution video showing how it would be completed. The recommended order is: watch the lesson, attempt the exercise yourself, then compare against the solution video.

Optional sections

The Hands-on guides and the Vision AI Theory section are marked optional. The Final Exam draws no questions from optional sections — but Vision AI is still worth understanding, since it is where Tosca's control identification is heading.

Every training element in a lesson section (lessons, exercises, notes, knowledge checks) must be completed before the Final Exam unlocks. Some exam questions are exercise-specific, so skipping the hands-on work will leave questions you cannot answer.

Some exercises ship with attached files — download them before starting that exercise. The course also includes Cheat Sheets and Hands-on Use Case material as reference.

Exercises, diagrams and practice feedback are available in the interactive lesson.
