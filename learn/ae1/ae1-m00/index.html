What this course is about

Beyond the browser

A business process can span a web form, email, a document, a workbook, a Windows application and a mobile screen. These independent notes examine the Tosca technologies used for such steps.

One tool, many engines

TBox provides a shared model for Engines 3.0. Modules and TestSteps provide familiar building blocks; supported controls, ActionModes and prerequisites still depend on the selected technology.

The signed-in AE1 course describes training developed with Tosca 16.0. Its overview covers framework, Excel, PDF, mail, Windows, self-healing, file/folder operations, custom/image controls and mobile, with Vision AI marked optional. The local notes supplement this course with versioned public documentation.

Before you begin

The original course was developed with Tosca 16.0. Version differences can include functionality and deprecations, not only screenshots; consult the matching manual and upgrade changes rather than assuming every old example remains compatible.

Exercise prerequisite: create the AE1 workspace

Workspace and subset

The original download package contains both base and solution TSU subsets. Their object structures were read without importing or executing them. Use the base for exercises and the solution for comparison in an isolated training workspace; inspect the actual imported Modules/TestCases and version compatibility.

The 2026.1 manual places technology modules under Standard modules → Engines. Older subsets can use different folder names; navigate the actual imported tree.

The source notes that an imported subset may not be immediately visible: search under Section and open it. Reading the provided solution or its stored logs does not count as a new execution of the tests.

How the course is structured

Learning workflow

The original welcome recommends video lessons, associated practice exercises and solution review. It describes eleven lessons including two theory lessons, with Hands-on guides and Vision AI Theory optional. The welcome states that the course Final Exam excludes those optional sections. This is the declaration for this Academy course, not a general rule for other certifications.

The course welcome requires lesson training elements, including exercises, notes and knowledge checks, to be completed before the Final Exam is accessible. A local Quilyn quiz score is independent practice feedback and does not unlock the Academy exam or issue its certificate.

Exercises, diagrams and practice feedback are available in the interactive lesson.
