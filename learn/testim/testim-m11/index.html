CLI actions vs. custom (browser) actions

CLI actions and validations

CLI actions/validations execute Node.js in the connected CLI environment; browser custom actions execute in the browser. Node.js can use configured packages and authorized resources, but network access, credentials and dependencies still need setup.

Browser DOM access and Node.js resource access are different capabilities. Browser/API checks can also validate server-provided results; direct database-driver access is the scenario-specific CLI use case, not a ban on all browser-based backend assertions.

Copilot assistance for supported coded steps

Generate a draft, then insert and test it

The Coding Assistant documentation explicitly lists Add CLI Validation among supported steps. Open Write code with AI, acknowledge the notice and request code. Use Paste code at cursor or Copy code to insert it; appearing in chat does not automatically install the implementation.

The original Academy CLI-action recording was unavailable. This local guide uses the explicitly listed CLI validation path rather than certifying every action variant. Review runtime, parameters, package bindings and returned Promises before relying on the generated draft.
