Duplication levels: scoring how much repetition exists

The duplication score

Testim measures how much duplicate step content exists across a project as a numerical score from 0 to 100, following the DRY (Don't Repeat Yourself) principle — the more identical step sequences appear across multiple tests, the higher the score.

The Auto Grouping workflow

Auto Grouping is the discovery and consolidation workflow; the resulting Shared Group then works the same way as any other shared group covered earlier — one edit propagates to every calling test.
