Enabling and authenticating API access

Plan restriction

API access is a professional feature, available only to projects on the professional plan — it isn't something every project tier has access to by default.

Generating an API key

Go to Settings → API, click Generate API Key, and name it. The key's value is shown once; you must copy it immediately and click Done, since that display is the only time the raw value is visible.

Authenticating requests

The API key is used in the Authorization header as a Bearer token: Authorization: Bearer PAK-[your-api-key]. For calls involving encrypted credentials (e.g. POST /tests/run/{testId}), the user-access-key value is instead added to the X-User-Access-Key field.
