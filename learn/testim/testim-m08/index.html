Uploading and structuring test data

Supported formats and limits

The Setup-step Excel/CSV workflow uses the first row for parameter names, then subsequent data rows for individual data sets, with a documented 1200-row limit. Test data must fit the documented 2 MB limit. The separate reusable Test Data library supports CSV, JSON and Excel; do not conflate that resource workflow with embedded Setup data.

Multiple ordered data sets

A single file can define multiple ordered data sets, letting one test run repeatedly against a whole matrix of input combinations instead of a single hardcoded scenario.

Column headers name parameters; data rows supply their values. Uploaded data is a snapshot: changing the local file requires re-upload, while an external-source configuration can parse its source on each run.

Config File vs. Params File for data-driven CLI runs

Config File overrides

A Config File can override the Visual Editor's test data at either the execution level or a specific test level (via overrideTestData) — and it's also how an external data source (like a linked CSV file, or a database) is supplied instead of an uploaded file.

Params File

A params file supplies execution-wide parameter values. JSON is supported; current documentation also supports JavaScript/module.exports. Config hooks with overrideTestData can target named tests. Verify precedence, including the separate reusable-file Prioritize test data option, instead of assuming every source always overrides every other.

Where the multiple data sets actually run

Editor run vs. CLI/Scheduler run

For the documented embedded Setup data workflow, ordinary editor playback runs the first data set. CLI, Scheduler or local suite execution can run the ordered data sets; inspect each data-set result. This is scoped to that workflow, not certification that every newer reusable-file option has identical playback behavior.

This is a common trap: seeing a single successful editor run and assuming the whole data set matrix has been exercised, when only row one has actually been used.
