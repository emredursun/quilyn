Installing and running via the CLI

Installation

Use a supported Node.js LTS/runtime and install the npm CLI package. The documented global workflow is npm install -g @testim/testim-cli followed by testim connect; a local package install needs the applicable local launcher rather than assuming a global testim command appears.

Why use the CLI at all

CLI supports configured test selection, grids, parallelism, data sets and CI invocation. It is not the sole mechanism for all non-local execution: the editor can run a single grid test and Scheduler can trigger configured matrices.

Configuration file

A config file (e.g. testimConfig.js) is created and passed to the CLI runner as a parameter, pointing to its path if needed. It can define the project ID, token, labels selecting which tests to run, the Selenium grid to use, and base URL overrides.
