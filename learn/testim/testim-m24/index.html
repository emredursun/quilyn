Beyond a single run: the Insights dashboard

TestOps Dashboard

Part of the broader Insights area, giving a higher-level view than the Reports tab alone — pulling together quality and activity signals so a team lead or consultant can answer 'how healthy is this project right now' without digging through individual test runs.

Metrics that matter beyond pass/fail

Interpreting pass rates, failure types, average durations, and team activity together — not in isolation — is what surfaces genuine trends and problem areas. A single metric (say, pass rate) read alone can mask a real issue that only shows up when cross-referenced with, say, a spike in average duration or a specific failure type.

The Dashboard's panes, in detail

The 'Assigned to me' toggle filters every pane down to the current user's own activity/tests — EXCEPT Duplication Level, which stays project-wide regardless of the toggle.
