Loops in Testim: six repeat-group types

Where a loop lives

Repeat group configures a group’s repetition; Don’t repeat is the default. Execution conditions and failures can still skip or stop work. The documented maximum is 99 iterations for any loop type, not only fixed-count loops.

For each item, in depth

'For each item' loop

For each item applies grouped actions to similar matched elements, within the configured item count (maximum 99). Verify actual matched items, iteration results and any paging/virtualization; a loop does not guarantee every record in an arbitrarily large table was visited.

TESTIM_ITERATOR

TESTIM_ITERATOR is available within group loops and increments with iterations. It is not a general test-wide parameter outside that scope; use it only where loop parameters are supported.

Condition-based and fixed-count loops

While element / While element text is

While element tests Visible/Not visible; While element text is tests the target’s expected text. Visibility and DOM existence are not interchangeable. Condition timing can be configured; neither loop is unlimited.

Loop for

Runs the group a fixed number of times — either a literal number typed in directly, or a parameter holding a number, capped at a maximum of 99. Unlike For each item, this doesn't depend on matching elements on the page at all; it's a pure iteration count.

Custom

For loop conditions that don't fit any of the built-in types, Custom lets you define the condition as a JavaScript function — with optional JS/HTML parameters passed in, and its own timeout override separate from the test's general settings.
