Two types of API steps: Add API Action vs. Validate API

Add API Action

Used to get data returned from an API call — the data it retrieves can simply be used to check that something was returned (or extracted and used later), rather than asserting a specific value on the spot.

Validate API

Used to validate data returned from an API call — usually validating data directly against the backend, asserting the response matches an expected value rather than just retrieving it.

Both API step types support parameters in their documented fields. Choose action/validation for the required response use and assertions; parameterization is not exclusive to Add API Action.

Configuring an API step

Adding an API validation step

Hover over the arrow where the step should go, click the predefined-steps icon ('M'), then choose Validations to add an API validation step to a test.

URL and request method

Choose HTTP method and endpoint, then configure headers, authorization, body and assertions. Named Basic/Bearer authorization overrides manually entered authorization headers. A configured assertion runs before additional response code; failed assertions prevent that code from running.

Validating API responses against the UI

Use supported assertions or additional code to compare response data and UI values. A quick Send preview does not execute assertions/additional code; only static local parameters are supplied and dynamic values become empty strings. Request retries apply to failed request status, separately from assertion behavior.

Send via web page

Send via web page (checked = default)

Browser-context sending includes browser session information such as cookies where applicable. Verify effective authentication, cookie policy and page readiness; selecting this setting does not guarantee every request is authenticated.

Send via web page (unchecked)

Outside-browser sending avoids browser CORS restrictions. It does not bypass server authorization, network access or all failure causes; configure the required authentication separately.
