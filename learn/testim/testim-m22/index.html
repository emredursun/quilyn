CI integration recap: the CLI is the universal connector

One CLI, every major CI

The npm CLI can run from a suitably configured CI runner. Supported runtime, project/grid, credentials and network access are prerequisites; a shell command alone does not provision or validate an integration.

This is the same underlying mechanism covered for Jenkins earlier in this path — Azure DevOps integration (next section) uses the identical CLI, just wired into Azure Pipelines' own YAML syntax instead of a Jenkinsfile/build step.

Setting up Azure DevOps integration

Azure Pipelines setup

The Azure guide demonstrates runtime/CLI setup, execution and PublishTestResults JUnit collection. Its Node 10.x example is obsolete; validate supported runtime and secure credentials instead of treating the snippet as production-ready.

This cited workflow invokes tests and publishes JUnit results. It does not by itself map Azure work items; that is a scope statement about this workflow, not proof every possible Azure integration is unsupported.

Linking a test to TTM for Jira and viewing results

Finding the integration

Settings > Integrations > Test Management contains separate TTM and Xray modules. TTM setup uses a TTM API key and project selection; Xray requires its documented Jira/Xray credentials. Connecting a project does not map its individual tests.

Linking a test to a TTM for Jira test case

Map a Testim test from Setup properties to one or multiple TTM test cases. Bulk create-and-map skips tests already mapped and reports failures for retry. Only one TMS connection is supported at a time; disconnecting removes mappings.

Viewing results in TTM for Jira

Mapped Remote Grid runs report names and translated statuses to TTM execution results. Mandatory custom fields are unsupported. Mapping and authentication must remain valid; generating a run does not guarantee delivery.

Remote Grid reporting eligibility is separate from subscription quota: some local CLI/library runs count toward quota without qualifying for this TTM remote-reporting workflow.
