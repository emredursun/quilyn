Local runs vs. grid runs

Local run limitation

When running locally — from the editor or the Test List — tests can only run on Chrome. This is a hard constraint of local execution, not a configurable setting.

Running on multiple browsers

To actually run on Chrome, Firefox, Safari, and Edge — simulating different desktop and mobile browsers in parallel — you need to use the CLI or Scheduler, not the plain editor. Execution can target Testim's own grid or any compatible Selenium grid.

Grid configuration via CLI

The grid to run against is set via the CLI's --test-config option, updating the grid parameter to point at Testim's grid or a compatible Selenium grid.
