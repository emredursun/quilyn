Local runs vs. grid runs

Local run limitation

When running locally — from the editor or the Test List — tests can only run on Chrome. This is a hard constraint of local execution, not a configurable setting.

Running on multiple browsers

Use CLI/Scheduler with supported browser/OS configurations for a cross-browser matrix. The editor also supports a single grid test. Supported combinations depend on the grid; selecting desktop browser configurations is not evidence of physical-device or native-mobile coverage.

Grid configuration via CLI

--grid selects the configured grid by name. --test-config selects browser/OS/resolution or other test configuration overrides; these flags have different roles. Verify both target infrastructure and the supported browser configuration.
