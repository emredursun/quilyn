Generating custom steps with generative AI

Testim Copilot

Uses generative AI to automatically create JavaScript code for custom code steps from a text description — letting less-technical testers produce working custom action steps without hand-writing the JavaScript themselves.

Using the Coding Assistant

Create a custom step, then click 'Write code with AI'. Inside the assistant's chat, typing '/' surfaces special commands. For Generate specifically, you type a prompt describing the desired code, press Enter (or click Send), and the generated JavaScript appears directly in the chat pane.
