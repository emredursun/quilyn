Adding steps to an existing test

When a test is missing steps

After running a test with debugging, you may find it's lacking some steps, or that some steps are outdated and need re-recording. Rather than re-recording the whole test from scratch, you can add steps manually or record just the missing portion through the AUT.

Inserting recorded steps at a position

Hover over the arrow between two existing steps where the new steps should go, click Start recording at this position, then record the additional actions on the AUT window — the new steps are inserted exactly where the arrow was, not appended to the end.

Start Recording vs. Start recording at this position

Testim actually offers two distinct entry points: the plain 'Start Recording'/Record button (available while execution is stopped) appends new steps to the END of the test, while 'Start recording at this position' — triggered from the arrow between two steps — inserts steps at that exact mid-test point instead.

Setting up the AUT state before recording mid-test

Before clicking 'Start recording at this position', first run the test up to that point (e.g. using a manual breakpoint) so the AUT is actually displaying the correct screen state — recording blind from the wrong state would capture the wrong actions. Once done, click Stop recording to finish.

Combining recording with debugging

Isolating the exact cause

Debugging tools — breakpoints and step-by-step execution — let you isolate the exact steps leading to an error and recreate the issue consistently, which is what tells you precisely where a missing or outdated step needs to be inserted, rather than guessing.
