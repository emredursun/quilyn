CSV and PDF exports

Exporting to CSV

CSV exports apply the chosen view/filter scope. Execution Runs exports executions; Test Runs exports individual runs (CSV is documented only for Counted Runs); Test Library exports test metadata, not the same result table. For Test Runs, the visible 200-result default does not truncate the matching CSV results. The export guide documents professional-plan entitlement.

Exporting to PDF

The result editor’s three-dot menu offers Generate PDF run report. Share it as a report of the selected run, not proof of complete requirement/code coverage or all project tests. The export does not execute or edit tests.

Exercises, diagrams and practice feedback are available in the interactive lesson.
