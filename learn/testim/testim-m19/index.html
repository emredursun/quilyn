CSV and PDF exports

Exporting to CSV

From Runs > Test Runs, the Advanced Filters button narrows the list of execution runs to export, then Export to CSV downloads them. Exporting is also available from the Test List > Tests view. When there are more than 200 results, the CSV download still contains all of them, not just the first 200.

Exporting to PDF

Testim can generate a detailed PDF report of test run results — a shareable, presentation-ready format with execution data, test coverage, and pass/fail status, suited for stakeholders who don't need the raw CSV.

Exercises, diagrams and practice feedback are available in the interactive lesson.
