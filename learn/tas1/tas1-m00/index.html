Prepare an independent practice environment

These notes describe Tosca On-Premises 2026.1, not a certified reproduction of the Academy course. Commander requires a supported Windows environment. For another host, arrange compatible Windows access and verify architecture, virtualization and organizational support; no named hypervisor or Boot Camp configuration is certified here.

Independent guidance: use an authorized disposable application, test credentials and reversible data. Do not assume a publicly reachable website permits every automation action.

Install a supported Commander environment

The current requirements specify 64-bit Windows 10/11, an i5 dual-core 2.4 GHz CPU, 8 GB RAM (16 GB recommended), 10 GB storage plus 1.5 GB system-drive installer cache, and 100 Mbit/s network. Recheck the linked matrix for your release and engine.

The software list includes .NET 10 Desktop Runtime and Hosting Bundle, Visual C++ redistributables and WebView2. WebView2 must be installed beforehand; use the current matrix rather than the obsolete .NET 4.7.2-only advice.

Launch the installation executable and follow its checks. Choose the default Commander components or a custom setup; inspect the final summary and logs for failures. Keep Tosca_Projects persistent and do not place it or APPDATA on a network drive. Browser extensions can be selected during setup.

Configure the assigned license

Use the license type provided by your administrator or training entitlement. For online node-locked activation in Tosca 2023.2 or later, open Project → License, then Setup → Activate licenses → Local Machine. Enter your Activation ID and total quantity, activate, then use Setup → Change connection to select the local machine. Internet access through TCP 443 is required. This is not a universal .lic import procedure.

In Manage, select Cloud License, Local Machine or License Server and apply to inspect availability and validity. Refresh recently changed allocations. Returning checked-out licenses may be required to inspect the rest of the pool. Independent guidance: obtain your actual eligibility, expiry and fulfillment terms; no free-license or 30–90-day duration promise is made here.

Connect an assigned cloud license server

An administrator must add your account to the intended cloud license server. In the license configuration, choose Setup → Change connection → Connect to Cloud hosted License Server. Sign in with Support Hub credentials; enable Use default proxy when applicable. A successful connection returns to the start screen.

Independent troubleshooting: a later license prompt is not proof of a corrupted installer or a missing file. Inspect the configured source, entitlement availability, validity and connectivity before contacting the license administrator.

Prepare local Chrome scanning

For XBrowser/XScan browser automation, install the Tricentis Automation Extension through Tosca setup, the browser or the documented manual route. XScan can direct you to the store if the extension is missing or outdated. In Chrome, add and confirm the extension, allow access to file URLs as documented, and inspect the Automation possible status.

Independent guidance: configure the actual browser being scanned, not an unrelated browser on another host. For a Windows guest running the local test, prepare that guest browser. This local setup guidance does not rule out separately configured remote automation. Do not diagnose every scanning failure solely from administrator privileges.

Verify readiness without guessing the cause

Independent checklist: confirm Commander launches, the intended license is usable, the target browser has the required extension, and the authorized application is reachable. Record the exact failure and inspect the appropriate component; a license prompt, scan failure and slow guest do not have one universal fix.

Do not treat 4 GB as the documented Commander minimum. Allocate resources against the current matrix and the rest of the workload. A successful environment check is preparation, not proof that an application test passed.

Check your own Academy completion requirements

Academy enrollment, award names, course prerequisites and certificate policies can change. The gated course and credential article were unavailable for verification. Check the requirements and award record for your own enrolled course; this independent module does not promise a badge, certificate, points or a particular training-license offer.
