Overview: What You Need Before Starting

Three Prerequisites

To begin the AS1 course, ensure you have all three of the following:

  • Tricentis Tosca On-Premises installed on your machine
  • A valid Tosca license (request via the Tricentis Support Hub)
  • Tricentis Automation Extension installed in Google Chrome
  • Download Tricentis Tosca On-Premises
  • Request a Tosca training license
  • Install Browser Extension Instructions

Windows Only — macOS Limitation

Tricentis Tosca On-Premises is a Windows-only application. It does NOT run natively on macOS.

  • macOS users must run Tosca inside a Windows VM
  • Supported VMs: Parallels Desktop (paid), VMware Fusion (paid), Oracle VirtualBox (free)
  • The Chrome extension must also be installed inside the VM — not on the macOS host

System Under Test (SUT)

The course SUT is the Tricentis Demo Web Shop — hosted online, no local server setup required.

  • Tricentis Demo Web Shop

Step 2: Request a Training License

Tricentis Support Hub

Free training licenses are requested at support-hub.tricentis.com. You need a Tricentis account (free registration) to submit a ticket.

Training licenses are typically valid for 30–90 days. Request yours 1–2 days before you plan to start the course — activation is not instant.

Troubleshooting: Tosca Commander License Pop-ups

Tosca keeps showing a license pop-up on launch?

This usually means Tosca Commander isn't connected to a valid license source. If your organization uses a Cloud License Server (instead of, or in addition to, a local .lic file), connect Tosca directly to it.

  • Connect to your cloud license server

Step 3: Install the Tricentis Automation Extension

What It Does

The Tricentis Automation Extension is a Chrome browser plugin that enables XScan to inspect and interact with web application elements. Without it, web automation is not possible.

  • Tricentis Automation Extension — Chrome Web Store
  • Full Browser Extension Install Guide

macOS VM users: the extension must be installed in Chrome INSIDE the Windows VM — not in the Chrome browser on your macOS host. Tosca can only communicate with the local VM Chrome instance.

Step 4: Verify Your Setup

Tricentis Academy Certifications and Badges

Finishing AS1 does not end with a formal certification exam like Pega's CSA/CPBA. It ends with the course's final quiz, which earns you a Badge and points — not a Certificate. Badges appear on your Academy "Badges" page with a shareable verification link; Certificates appear on the "Courses" page as a downloadable PDF.

Certificate vs Badges: What is the difference?

The Tricentis Academy offers a robust certification program recognising users' skillsets, capabilities, and project readiness. This program provides curated learning journeys intended to enable partners to build competence within specific testing roles. Each path is designed with self-paced online learning, consisting of carefully chosen courses covering skills necessary for success in each role.

AS1 is on the badge-only list above. To earn an actual downloadable Certificate, you'd need to complete the full Tricentis Tosca Product Consultant path, which includes AS1 as just one of several required courses.
