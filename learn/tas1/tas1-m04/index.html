Rescan

Rescan

Re-scans an existing Module's Controls against the live SUT to update their technical properties — without deleting or recreating the Module.

Do NOT delete and recreate a Module when the SUT changes — this breaks all TestCase references. Rescan UPDATES the existing Module in place, preserving all references.

Rescan is like updating your contact book when a friend moves — you don't create a new contact, you update the existing address so all references to that contact remain valid.

Value Range

Value Range

A property set on a Control within a Module that defines the list of acceptable values for that Control. Acts as a validation layer at the Module level.

Value Range Syntax (confirmed exercise detail)

When entering multiple values into a Value Range, separate them with semicolons and use NO spaces between values.

  • Correct: AutomationDiscount2;PercentageTotal;PercentageShipping;FlatTotal
  • Wrong: AutomationDiscount2, PercentageTotal (commas + spaces)
  • Wrong: AutomationDiscount2; PercentageTotal (spaces after semicolons)
  • Separator = semicolon ( ; ) only. Spaces would be treated as part of the value.

Value Range is defined at the Module/Control level — it applies everywhere that Control is used, across all TestCases.

Module Merge

Module Merge

Combines two separate Modules that represent the same SUT element into one authoritative Module. After merging, all TestSteps referencing either original module are updated automatically.

Target Module vs. Source Module (key exam concept)

In a merge, one Module is the Target and the other is the Source.

  • Target Module = the one you KEEP. It survives the merge.
  • Source Module = the one that gets DELETED after its selected Attributes are copied into the Target.
  • If the wrong Module is set as Target, use the 'Switch Modules' option to swap them.
  • You choose which Attributes to bring from the Source into the Target.
  • Tosca automatically links Attributes that have identical properties in both Modules.

Module Merge is like deduplicating your contact list: if 'John Smith' is entered twice with slightly different phone numbers, you merge them into one complete, authoritative entry.
