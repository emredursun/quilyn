Rescan without losing the model link

Rescan updates an existing model while preserving its TestCase references. Open the appropriate SUT screen; right-click the Module → Rescan or Ctrl+Shift+R. WebDriver-created XBrowser Modules have a separate Rescan WebDriver command.

Add new controls deliberately. Unmapped controls can be mapped to controls of the same business type; inspect old/new property choices and save the update. Independent guidance: rerun affected tests rather than treating reference preservation as proof of passing behavior.

Small identifier adjustments can be made in Properties. Do not delete a used Module simply to rescan it: that loses its links. Replacing an unusable model requires a deliberate migration before removing the original.

ValueRange is a selection aid

ModuleAttribute ValueRange supplies dropdown choices in TestStepValues; user-specific values can also be entered. It is not an assertion that the SUT accepts only those values or a universal runtime validation lock.

Separate entries with semicolons. Exact strings include spaces: EUR;USD;GBP names three entries without leading spaces. Spaces inside a legitimate value remain significant. XScan may populate choices from ComboBox/ListBox controls.

Independent guidance: define allowed application behavior separately and test both valid and invalid inputs where appropriate. A dropdown suggestion does not replace those expectations.

Merge compatible XModules

Merge Modules requires the same technology. Select the intended target first, then the source; inspect the assistant and use Switch Modules if needed. Resolve conflicting properties deliberately, rather than deleting a steering parameter just because it raises a warning.

A completed full merge retains the target, removes the source and maintains references. If required objects cannot be checked out in a multi-user workspace, Partial Merge can leave the source in place. Check the outcome before treating consolidation as complete.

Independent guidance: matching names or a shared page do not prove model equivalence. Check controls, identifiers and affected TestSteps before and after consolidation.

Independent maintenance exercise

On a disposable compatible model, inspect rescan mapping, configure exact ValueRange suggestions and compare a full merge with a checkout-blocked partial merge. Original Academy Exercise 18 and its figures were inaccessible; this is independent practice, not an executed course exercise.
