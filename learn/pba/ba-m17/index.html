Exploring and Analyzing Application Data

The Explore Data landing page

Pega Platform lets you easily explore and analyze your application's data from the Explore Data landing page in App Studio. Organizations analyze operations to understand the performance of their teams and processes.

Insight

An Insight transforms a data query into a TABLE or a VISUALIZATION (chart) that you can save and SHARE between users. Insights turn raw Case/application data into something stakeholders can read and act on.

Benefits of Insights

Insights provide self-service, low-code data analysis:

  • Business users can answer operational questions
  • Monitor team/process performance
  • Share results — without writing code or exporting to another tool

An Insight is a saved 'lens' on your data: point it at your Cases and it renders the answer as a clear table or chart you can pin up and share, instead of digging through raw records each time.

Table and Chart Insights

Table Insight

Presents query results as rows and columns — ideal for detailed, record-level review (e.g., a list of Assistance Request Cases created in the last 30 days with key fields).

Chart Insight

Presents query results as a visualization (e.g., bar, line, or pie chart) — ideal for spotting trends, comparisons, and distributions at a glance (e.g., Cases per day, by status, or by region).

A table Insight is the spreadsheet view (every row visible); a chart Insight is the dashboard gauge (the shape of the data at a glance). Pick the one that answers the question fastest.

The Role of BIX in Data Analysis

BIX (Business Intelligence Exchange)

BIX is Pega's data EXTRACT capability that pulls application data OUT of Pega into external databases or files so it can be analyzed in external business-intelligence/reporting tools — suited to large-scale, enterprise, or cross-system analytics.

Insights vs. BIX

Two Pega data analysis options:

  • INSIGHTS — analyze and visualize data IN Pega (in-platform, self-service)
  • BIX — EXTRACTS data to external systems for analysis OUTSIDE Pega (use when combining with external BI tools)

Insights is reading the data where it lives (in Pega); BIX is the delivery truck that ships copies of the data to an external warehouse (a data warehouse/BI tool) for heavy-duty analysis.
