Running a message can reveal actual behavior, generated identifiers and integration errors. Independent guidance: compare these observations with the contract; do not copy observed values into expected results as proof they are correct. A successful status still needs business assertions.

Independent example: create and verify a shop

Payload fields are API data. They are not automatically Tosca Reusable TestStepBlock Business Parameters; exported Module Attributes and assertions are configured separately.

Independent exercise: create an item

Use an authorized disposable sandbox to configure a creation request, inspect its response and retain the created identifier. Original Academy video/exercise files are inaccessible and uncertified.

Independent exercise: verify an item

Retrieve the created resource and compare its fields to independently defined expected values. Check negative behavior and cleanup requirements from the contract. This is independent guidance, not a verified Academy exercise solution.
