The Five Tabs of the Message Section

TabWhat it shows
PayloadThe request or response message itself. On first load it's a structural template; fill it in to send real data.
MethodThe HTTP Method used for the request (GET, POST, PUT, DELETE...). If Method is GET, the Payload may be empty depending on the SUT.
EndpointThe API's base URL.
ResourceThe resource identifier for this endpoint.
ParamsDisplays and edits parameters, such as the "key" Service Access Key.

It's valuable to test directly in the API Scan before exporting anything to Tosca: this is where you discover the real default values returned by the server, which you'll need later as genuine test data in the exported TestCase. Modifications to a Message can also be made right here if a result isn't what you expect.
