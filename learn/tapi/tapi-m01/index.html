APIs and network services

API

An application programming interface defines how software components interact. It can be local or exposed through a network service; it is not necessarily a separate messenger program.

Network service

A service interface can be reached across a network. The HTTP examples here use request and response messages; the public World Wide Web is not required for every private network API.

A mouse is a device that software can access through interfaces, not literally an application programming interface itself.

SOAP, REST and HTTP methods

Different kinds of abstraction

SOAP defines a messaging framework; REST is an architectural style with constraints including a uniform interface and stateless interactions. Neither term means every endpoint implements every possible method.

MethodIntent
GETRetrieve a selected representation of the target resource.
HEADLike GET, without response content.
POSTAsk the resource to process the supplied representation according to its semantics; creation is one use.
PUTCreate or replace the target resource state with the supplied representation.
DELETERequest removal of the association between the target URI and its functionality.

The SOAP 1.2 HTTP binding maps its request-response pattern to POST and its SOAP-response pattern to GET. Other bindings can differ; SOAP is not universally POST-only. Inspect the service binding and contract.

SOAP messaging uses an XML-based envelope model. REST representations are not restricted to one format; media types and the service contract determine accepted representations, such as XML, JSON or text.

XML documents

XML

Extensible Markup Language represents document data and logical structure through markup. It can be used in messages or local files. Well-formed XML is not automatically valid against a schema or correct according to business rules.

Authentication and independent practice

Choose a permitted test service

Use an authorized sandbox with a published API contract. The historical DemoWebShop/Coffeeshop course mapping and training endpoint availability were not verified, so these notes do not require either service.

Follow the service contract

Configure credentials in the required location: the API Scan message section exposes authentication, parameters and headers separately. A query parameter named key and a 24-hour lifetime are not universal REST requirements.
