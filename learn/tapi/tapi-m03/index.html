Home Menu: Save, Open, Close

The Home Menu's six options

Save, Open, and Close (left-hand side) manipulate the API Scan project as a whole. Duplicate, Delete, and Rename (right-hand side) manipulate individual elements of the project, such as messages or operations.

When working in an environment where Tosca Commander is not installed (the standalone API Scan only), you cannot export the API project directly into Tosca — but you can still Save it to disk, and use that file later as a Tosca Subset.

Duplicate, Delete, Rename

Duplicate

Highlight a folder or message and click Duplicate to create a copy in the same root folder. The copy keeps the old name with a number appended (e.g. duplicating "Ex 2" creates "Ex 3").

Delete

Highlight an element and click Delete (or press the Delete key) to remove it from the project file.

There is no Undo in the API Scan. An accidentally deleted element cannot be recovered without re-loading the file or re-scanning the URI. Save your project regularly, or duplicate the main folder elsewhere first, as a safety net.

Rename

Either highlight an element and click Rename in the Home Menu, or click the element and press F2. All three actions — duplicate, delete, rename — are also available from the right-click context menu on any element.

Numerical-prefix naming convention

The API Scan sorts folders, payloads, messages, and components alphabetically. Because of this, best practice is to rename elements with a numerical prefix matching the order they'll be used in the TestCase — e.g. "01 Get Address", "02 Add to Cart".
