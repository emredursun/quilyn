Project persistence and payload persistence

Documented Home-menu commands

Save as saves an API Scan project to a chosen file; Save or Ctrl+S saves to the same file after it has been saved before. Open opens a project and Close closes the current project. These are project operations, distinct from Payload-tab file operations and export to Commander.

Keep project and payload backups distinct. A payload file is not a complete message backup of headers, authentication and transport settings, nor a full project backup. Use the documented export workflow for Commander artifacts.

Duplicate, Delete, Rename

Duplicate

Duplicate copies the selected folder or message; it is also available in the context menu. Inspect the copy and rename it deliberately; the accessed article does not certify an incrementing-name algorithm or exact destination for every object type.

Delete

Delete removes the selected folder or message. Confirm the intended selection and save a recoverable checkpoint before deletion.

The accessed docs do not establish a universal Undo/recovery policy for API Scan. Do not depend on an unverified shortcut, automatic archive or autosave; preserve an explicit checkpoint before deleting data.

Rename

Use Rename in the Home menu or the context menu of the selected project object. The accessed API Scan pages do not verify an F2 shortcut; a Commander shortcut list is not proof of API Scan behavior.

Independent naming convention

An optional 01 / 02 / 03 prefix can communicate intended sequence to reviewers. Do not assume display sorting defines TestCase execution order; inspect and configure the exported test steps separately. The accessed docs do not establish universal alphabetical sorting of every object.

Independent hands-on workflow

Save a small project, save one payload separately, duplicate and rename a message, then inspect what each saved artifact contains. Load only a disposable payload because loading replaces current content. Academy video/exercise files require access and have not been verified.
