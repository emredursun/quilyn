What This Course Covers

"Tricentis Tosca Deep Dive - Automating API test cases" covers Tricentis Tosca's standalone solution, the API Scan, which enables automated testing of application programming interfaces. The course covers how to use the API Scan to gather the technical information of your API and how to add the relevant business information to run your tests. It also explores automation techniques for REST APIs, SOAP APIs, and XML files.

The API Scan is standalone

The API Scan is also a standalone program (ApiScanStandalone.exe). No Tosca license is needed and no Tosca installation or testing knowledge is required to operate the API Scan by itself. This makes it easy to involve developers in the testing process: send them the .exe file, they scan the API, save the resulting messages, and send them back as a subset that can be manipulated and tested — without installing or activating the full Tosca package.

Throughout this course, the API Scan is always opened from inside Tricentis Tosca itself (Home ribbon > API Testing tab), rather than the standalone .exe, since every exercise exports results into Tosca Commander.

Troubleshooting: Tosca Commander License Pop-ups

Tosca keeps showing a license pop-up on launch?

This usually means Tosca Commander isn't connected to a valid license source. Since every exercise in this course exports API Scan results into Tosca Commander, a working license connection is required even though the API Scan itself needs none. If your organization uses a Cloud License Server, connect Tosca directly to it.

  • Connect to your cloud license server

Why API Testing Matters

API

Application Programming Interface — an interface created with the application in mind rather than the user. Where a UI is designed to be human-readable, an API is machine-readable: it speaks the language of the software directly.

Historically, API testing meant developers hand-coding and hand-maintaining scripts. The API Scan removes most of that manual scripting and maintenance burden, bringing developers and QAs closer together in the same testing process.
