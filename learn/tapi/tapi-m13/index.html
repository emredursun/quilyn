Inserting Data Into an XML File

Open/Create XML File and Save XML File

Tricentis Standard Modules used for common XML steering operations across any XML file. Open/Create XML File loads the Resource from a given file path; Save XML File writes the in-memory Resource back out — either overwriting the original file (leave the file path empty) or creating a new file (specify a new name). Tosca can only save into an existing folder.

Resource must match EXACTLY across every TestStep in the TestCase — Open, Insert, and Save all need to reference the same Resource value, or Tosca won't know they're working on the same in-memory data.

Verifying Data in an XML File

Select → Constraint → Verify

To check that inserted data landed correctly: Select on the outer container nodes (e.g. Contacts, Product) tells Tosca where to look. Constraint on a unique identifying field (e.g. an Id or Email) narrows the search down to exactly the one entry just created. Verify on every other field then checks the actual stored values against what you expect.

The same Module used for the Insert TestStep is reused again, unmodified, for a Verify TestStep — only the ActionModes and values on each TestStepValue change between the two.
