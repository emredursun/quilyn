Opening the API Scan

Two ways to open the API Scan

The API Scan can be started either from the ApiScanStandalone.exe file directly, or from inside Tricentis Tosca via the API Testing tab on the Home ribbon. This course always opens it from inside Tosca, since every exercise exports results into Tosca Commander.

The first time the API Scan opens there is nothing loaded; every subsequent time it defaults to reopening your last saved project.

Operations, Messages, and the Payload

Operations and Messages

Operations contain Messages. A Message's content is only loaded the first time you click its Operation — this avoids the performance cost of generating content for every message up-front on a large, complex API.

Payload

The area where you interact with and check responses. When a Message is first selected, the Payload shows a representation of what can be sent as a Request. Sending that default content usually returns an error — you must fill in appropriate data first. Some Requests (e.g. a GET) can have an empty Payload by design. Unneeded elements can be deleted from the Payload if they aren't relevant to what you're testing.

Status CodeMeaning
200 OKThe request succeeded
404The resource was not found
500The server is down or unreachable
