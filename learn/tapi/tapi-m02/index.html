Opening and scanning

Launch paths

Select API Testing > API Scan in Commander, or launch ApiScan.exe in %COMMANDER_HOME%. The Modules menu also offers Scan Application > Non UI > API Scan. These are current documented entry points, not an arbitrary executable-distribution guarantee.

Operations, requests and responses

Operations and messages

For scanned service definitions, API Scan initially displays empty operations and generates them when selected. A simple file can be imported directly as a simple message; do not generalize the service-operation behavior to every scanned file.

Configure a message

Use Method, Endpoint and Resource together with Payload, Params, Auth and Headers. Inspect generated example data against the contract; it is neither guaranteed valid nor guaranteed to return an error. The Home menu Request and Response controls select the corresponding view.

StatusMeaning
200 OKThe request succeeded; inspect content and business expectations.
201 CreatedThe request created one or more resources.
404 Not FoundNo current representation was found, or the server is unwilling to disclose one.
500 Internal Server ErrorAn unexpected server condition prevented fulfillment; this is an HTTP response, not evidence that no server was reachable.

Independent hands-on workflow

Scan an authorized small API definition, generate one service operation, configure valid and invalid requests, and inspect response evidence. The original Academy video and exercise file require access and have not been verified; historical Shops_Post naming and token rules are not certified here.

Exercises, diagrams and practice feedback are available in the interactive lesson.
