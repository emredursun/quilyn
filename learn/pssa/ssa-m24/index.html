Application performance issues

Choose the right mechanism

A slow interaction can arise in the client, application server, rule processing, database or external service. Reproduce the reported path and use guardrail warnings plus measured evidence. A high compliance score is useful but does not prove the absence of performance defects.

Worked example: A lookup is slow only for a large account. Capture its query volume and duration before treating it as a general frontend problem.

Rule assembly and performance

Choose the right mechanism

Rule assembly generates and compiles executable code for rules; rule caches avoid repeating resolution and retrieval. Newly deployed rules can make initial use slower. Compare cold and warm behavior; numerous distinct ruleset lists can increase cache resource demands.

Worked example: After a release, the first use of a rule is slower than repeats. Compare assembly and cache metrics to avoid measuring only the initial compile as steady-state behavior.

Diagnosis of database issues

Choose the right mechanism

Use PAL deltas to locate database cost, then inspect expensive statements with Database Trace and database tools. Consider filters, indexes, reporting-property optimization, data volume and transaction boundaries. Do not add arbitrary indexes or expose sensitive columns without analyzing the query and data requirements.

Worked example: A report filters on an unoptimized property inside case data. Confirm the query plan and reporting requirements before optimizing the relevant property and retesting.

Performance debugging tools for Constellation applications

Choose the right mechanism

Constellation uses stateless DX API requests with significant client orchestration. Inspect browser network/timing information and trace the relevant Service REST processing. Request context differs from a traditional stateful portal session; use the trace's step-page context rather than assuming a persistent portal Clipboard.

Worked example: For a slow Constellation action, inspect its API request and response, trace the relevant Service REST rule and compare client rendering time with server processing time.
