Log files

Choose the right mechanism

The PEGA log contains operational information, warnings and errors. ALERT contains threshold-based performance events; ALERTSECURITY contains security alerts. Additional logs depend on configured appenders, such as BIX extracts or security-event logging. Capture timestamp, node and requestor context before correlating evidence.

Worked example: A failed connector at 14:10 has an exception in PEGA. A slow report around the same time has an ALERT event; correlate them rather than assuming all log types represent the same failure.

Alerts

Choose the right mechanism

An alert identifies a threshold or security event, not a fully established root cause. My Alerts focuses on session events by default; broader logs and PDC provide wider context. Use event frequency and affected interactions to prioritize investigation, while avoiding unnecessary sensitive data in diagnostics.

Worked example: One slow operation among many requests and repeated slow operations for nearly every user need different priorities. Check the interaction and recurrence in PDC before choosing a fix.
