Background processing

Choose the right mechanism

Queue processors handle queued items asynchronously; job schedulers wake on a schedule to run an activity. Queue individual work with Run in Background or Queue-For-Processing. Schedule recurring scans with a job scheduler. Neither choice removes the need for safe retries and observable failure behavior.

Worked example: After a document is submitted, queue its processing so the interactive case can continue. A nightly reconciliation that discovers records to process is a scheduled job.

Background process management

Choose the right mechanism

Queue processors manage their processing transactions; avoid adding conflicting object-save/commit steps to their activity. Job scheduler activities manage the read/write work they perform. Investigate broken items and repair the underlying cause before reprocessing; design external effects so retries do not duplicate them.

Worked example: A delivery notification may be retried after failure. Use a business identifier to prevent duplicate external notifications, and inspect broken queue items instead of repeatedly replaying a malformed request.

Node classification

Choose the right mechanism

Node classification assigns runtime work to suitable node types. Separate background workloads from web-user workloads where appropriate; moving work to another node does not fix inefficient code or eliminate shared database contention.

Worked example: Assign heavy batch jobs to background nodes while keeping web requests on their designated nodes. Recheck database load and user response times after the separation.

Admin Studio

Choose the right mechanism

Admin Studio exposes runtime management for queue processors, jobs, nodes, requestors and listeners. Use it to inspect health, failure counts and running resources. A configured but disabled processor is not evidence that queued work is being completed.

Worked example: In Admin Studio, inspect a processor's broken items and last failure, fix the cause, then use the supported reprocessing operation and verify completion.
