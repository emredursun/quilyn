Product Rule

Decision rule

A Product Rule (RAP) is the migration manifest; its generated ZIP/JAR archive carries the selected contents. Use Packaging wizard and Preview to verify Rules, associated data and required dependencies. Standard platform assets usually already exist on the target. A data instance’s Ruleset association supports packaging, not runtime access control. Accessible imported Rules may execute before the whole import finishes.

Worked example: A data instance associated with Lending is easier to include in its package, but this association does not prevent another application from accessing it.

Exporting an application, product Rule, or Ruleset using the Export wizard

Decision rule

Export scope can be application, Ruleset/version, Product or patch. Check in intended edits: a checked-out personal copy is not the exported version. Export the selected package and import it on the target. Inspect errors and Preview rather than assuming every required component is included. Production/delegated Rulesets may need explicit inclusion and permission to package unlocked versions.

Worked example: To send a targeted release to QA, preview the Product, check in intended edits, export the archive and import it on the target. Check production Ruleset inclusion explicitly.
