Data validation against a pattern

Choose the right mechanism

An Edit Validate rule checks a property's character format. A Validate rule can enforce broader business conditions and call Edit Validate at submission. Built-in patterns may validate on field exit; custom Java Edit Validate logic executes server-side. A valid format does not establish that an identifier exists or belongs to the user.

Worked example: An internal asset tag must match three letters followed by four digits. Check its pattern with Edit Validate, then separately check uniqueness or existence using application logic. Test valid, malformed, empty and boundary inputs.
