Case locking

Choose the right mechanism

Allow one user applies an exclusive lock when opening a case for editing. Allow multiple users permits concurrent opening and checks whether the persisted case changed when saving; a stale user must refresh. Locking protects data consistency and is separate from authorization.

Worked example: Two coordinators open a booking. With multiple-user locking, the first saves a new date; the second must refresh and reconcile rather than overwrite that update. Use one-user locking when a long edit must be exclusive.
