Field values

Choose the right mechanism

Field Value rules define allowed values separately from a property. Apply To class and ruleset context allow the same inherited property to have different permitted values. A short, static list shared by all contexts may instead live on the property. Frequently changing external data belongs in a data source rather than hundreds of field-value rules.

Worked example: The shared pyStatusWork property needs a custom Resolved-Returned value for Returns cases only. Add the value in the Returns class context; do not clone the standard property for every case type.
