Delayed Service-Level Agreement processing

Choose the right mechanism

Assignment Ready defines when an assignment SLA starts: immediately, after a fixed delay, or at a DateTime property. Creation and readiness can differ. This setting applies to assignment SLAs; do not assume it delays every case-level deadline.

Worked example: A settlement task is created at 10:00 but can start only at 16:00. Store today's settlement opening time in a DateTime property and start the assignment SLA then; a two-hour deadline is 18:00.

Assignment Urgency

Choose the right mechanism

GetNextWork uses assignment urgency. Assignment urgency combines the case contribution at assignment creation, assignment SLA increments and a manual assignment adjustment, capped at 100. A later manual change to case urgency does not retroactively update an existing assignment's case contribution.

Worked example: A case contributes 20, the assignment SLA contributes 10 and a manual assignment adjustment contributes 5. The assignment priority is 35 before later SLA increments.
