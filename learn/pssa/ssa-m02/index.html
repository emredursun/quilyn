Application versioning

Decision rule

Version format is major-minor-patch. Lock and roll creates an empty higher version for incremental edits; untouched Rules remain resolved from accessible earlier versions. Skimming consolidates latest eligible Rules from a selected major into a higher minor or major. Available, Final and Blocked are copied; Not Available is excluded; Withdrawn survives minor skims only. Check in work before versioning. New major/minor releases require application and Access Group updates; patch changes typically do not.

Worked example: Pricing:02-03-01 holds Rules A and B; 02-03-02 updates B. A minor skim consolidates A with the newer B. Lock and roll instead starts an empty editable version.
