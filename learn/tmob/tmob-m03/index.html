Preparing a physical Android device

Charging or file-transfer visibility alone does not establish debugging access. Check USB debugging authorization and adb devices before investigating the Agent connection.

Creating an Android emulator

Android Studio and the AVD Manager

Tricentis recommends Android Studio for emulators. Its AVD (Android Virtual Device) Manager creates emulator profiles by pairing a device definition (e.g. Pixel 7) with a system image (a specific Android version and CPU architecture).

For the documented TMA 2025.4 setup, run the emulator on the Agent host. This supported topology is not a claim that every remote Android connection is technically impossible.

Platform-specific gotchas

Google’s Android Studio Windows requirements checked on 2026-10-06 do not support ARM-based Windows CPUs. Choose a supported host for this setup or investigate a supported physical-device configuration; re-check the published matrix when versions change.

Getting AppPackage and AppActivity

Why these two values matter

For an installed Android application, specify its package and intended launch activity in AppPackage and AppActivity. Obtain these from the application owner or verified build configuration; a focused activity is not necessarily its launch entry point.

adb belongs to SDK Platform Tools. Use SDK Manager to install that package or check the Agent’s documented platform-tools directory for the executable; do not assume that every Android Studio installation already has it.

Application Path can install an Android APK. BundleID identifies an installed iOS application. Prefer AppPackage/AppActivity for the installed Android application rather than treating all other fields as APK-installation fields.
