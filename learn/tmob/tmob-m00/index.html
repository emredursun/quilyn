What this course is about

A deep dive, not a single lesson

AE1's 'Automating beyond web applications' course touches Mobile Engine 3.0 in a single lesson — enough to open a Mobile Scan and build one TestCase. This course goes much deeper: installing and configuring TMA yourself, preparing both Android and iOS targets, understanding Local vs Remote topologies, scanning native/hybrid/web mobile apps, and working through the full catalog of mobile-specific Modules and gestures.

One engine, three kinds of app

Mobile Engine 3.0 automates native apps (built specifically for iOS/Android), hybrid apps (a native shell wrapping embedded web views, common in cross-platform frameworks like React Native or Ionic), and mobile web (a site opened in the device's browser). The same Mobile Scan handles all three — the difference shows up in how controls are captured, not in a different tool.

This is a Deep Dive course and part of the Tricentis Tosca On-Prem Product Consultant learning plan — the same learning plan as AS1/AS2, TDS1/TDS2, and AE1. It assumes the AS1/AS2 fundamentals (Modules, TestCases, TestStepValues, ActionModes) are already comfortable.

What you will be able to do

Before you begin

Official course description: this course covers how Tricentis Tosca Mobile and the Tricentis Mobile Agent transform mobile test automation by streamlining processes and boosting test coverage — installing Tosca Mobile, configuring its architecture, and using its scanning and execution options for reliable, scalable mobile testing.

iOS automation cannot run from a Windows machine. If Tosca Commander itself runs on Windows, iOS testing needs a separate Mac running TMA, connected to the Windows machine as a Remote (TMA) setup — covered in the Connecting Tosca to TMA lesson.

How the course is structured

Setup first, automation second

Roughly half of this course is environment setup — installing TMA, preparing devices, wiring the connection — before a single Module gets scanned. That ordering matches reality: the large majority of 'mobile automation isn't working' problems in practice are setup and connection problems, not TestCase-authoring problems.

Every lesson pairs explanation with concrete, checkable steps (install commands, settings paths, TCP values) rather than abstract theory alone — mobile setup is where small details (a missing trailing slash, a disabled toggle) cause the most confusing failures.

Exercises, diagrams and practice feedback are available in the interactive lesson.
