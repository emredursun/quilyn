What this course is about

Original course and local study track

The Academy introduction is a 45-minute course developed with Tosca 2024.2. Its five topics cover getting started, installing Tosca Mobile and TMA, connection options, scanning options and execution options. This local track expands that outline with platform preparation and troubleshooting; the additional lessons are independent study material, not the Academy syllabus.

App types and engine paths

Mobile automation covers native apps, mobile websites and hybrid apps with embedded web content. A framework name alone does not determine whether an app is hybrid: React Native can produce native controls. The current guide distinguishes Mobile Engine 3.0 and Mobile Web Engine 3.0 scanning/steering paths.

The Academy lists software-testing and mobile-automation knowledge, AS1 training, access to Tosca with a valid Tosca Mobile license, access to TMA, and Android Studio setup as prerequisites. Check compatibility and entitlement for your installed versions.

What you will be able to do

Before you begin

The Academy knowledge, training and technical prerequisites are listed below. Additional target-preparation guidance comes from the versioned public manuals; it extends the introductory course.

TMA 2025.4 lists iOS hosting as macOS only. A Windows Tosca workstation can connect remotely to the supported Mac Agent. Older guides describe different host support; do not turn one version’s requirement into a timeless claim or assume Tosca Commander runs natively on macOS.

How the course is structured

Setup first, automation second

Prepare components, devices and connections before scanning and executing. This follows the documented workflow; it is not evidence that a particular percentage of lessons or most real-world failures concern setup.

Validate each layer with its logs and configuration. A scan success or device listing does not prove every execution prerequisite is satisfied.

Exercises, diagrams and practice feedback are available in the interactive lesson.
