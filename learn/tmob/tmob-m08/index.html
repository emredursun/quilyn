Android Snackbar

A dedicated Module for a transient component

Android Snackbar steers the Android Snackbar component specifically — the brief, auto-dismissing message bar that appears at the bottom of the screen (e.g. 'Item deleted — Undo'). Because it disappears on its own after a short delay, generic control-steering can miss it entirely; this dedicated Module exists to interact with it reliably within its visible window.
