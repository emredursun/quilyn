Getting TMA installed

A separate installer from Tosca Commander

TMA is installed separately from Tosca Commander using the package for its host operating system. Local/remote deployment changes topology and configuration, not the authoring model. Windows, macOS and Linux installation steps are different; use the matching official guide.

TMA 2025.4 specifies bare-metal hosts, not virtual machines. Do not infer that an unsupported VM deployment works reliably from an anecdote.

Starting TMA: tray launch vs command line

Default startup binds locally

The TMA 2025.4 CLI guide states that services bind to localhost by default. A default local start is suitable only when the caller can reach those local bindings; check actual configuration rather than assuming every customized GUI start has the same bindings.

Command-line launch with --rest-address — required for remote use

For the documented cross-machine connection, start with tricentis-mobile-agent start --rest-address <IP>:<port>. This binds the web server to the chosen address. Appium and gRPC have separate --appium-port and --grpc-address settings; use the endpoint required by each consumer.

A reachable console demonstrates access to that web endpoint, not that a device session or Appium connection will succeed. Check service bindings, network access and session logs separately.

Ports and firewalls

Distinguish service ports

The Tosca configuration guide documents 8585 as the default Appium port; the TMA preparation guide also uses http://localhost:8585/ for its interface. Remote examples use a configured REST binding. Inspect the actual endpoints and permit the necessary traffic; do not infer one universal REST port from an Appium example.

Test the required endpoint from the caller’s host and inspect Agent/session logs. A successful web response proves that specific endpoint responds; it does not prove a device is authorized or the requested session capabilities work.

The TMA console

Device Management

Device management lists detected devices and their information. Inspect availability before session creation, but a device entry or ready status is only one diagnostic signal. Authorization, capabilities, target app and network paths still need validation.

Keeping TMA up to date

Version alignment with Tosca

Check the release notes and documented compatibility for the installed Agent and Tosca versions. The TMA upgrade guide installs the matching OS package to replace the previous Agent and retain configuration/devices. Version numbers do not imply a required one-to-one matching release.
